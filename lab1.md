## Реализованные методы

### Блок n1 (базовые операции с числами)

- **1. `sumLastNums(int n)`** — возвращает сумму двух последних цифр числа
- **2. `isPositive(int n)`** — проверяет, является ли число неотрицательным
- **3. `isUpperCase(char x)`** — проверяет, является ли символ заглавным
- **4. `isDivisor(int a, int b)`** — проверяет, является ли одно число делителем другого
- **5. `lastNumSum(int a, int b)`** — возвращает сумму последних цифр двух чисел

### Блок n2 (условные конструкции)

- **6. `safeDiv(int x, int y)`** — деление с защитой от деления на ноль
- **7. `makeDecision(int x, int y)`** — сравнение двух чисел со строковым результатом
- **8. `sum3(int x, int y, int z)`** — проверяет, равна ли сумма двух чисел третьему
- **9. `age(int x)`** — склонение слова «год/года/лет» по числу
- **10. `printDays(String x)`** — вывод дня недели и всех последующих (switch без break)

### Блок n3 (циклы и строки)

- **11. `reverseListNums(int x)`** — выводит числа от x до 0 через пробел
- **12. `pow(int x, int y)`** — возводит x в степень y
- **13. `equalNum(int x)`** — проверяет, все ли цифры числа одинаковы
- **14. `leftTriangle(int x)`** — левый треугольник из `*`
- **15. `rightTriangle(int x)`** — правый треугольник из `*` с выравниванием

### Блок n4 (массивы)

- **16. `findLast(int[] arr, int x)`** — индекс последнего вхождения x или -1
- **17. `add(int[] arr, int x, int pos)`** — новый массив со вставкой x в позицию pos
- **18. `reverse(int[] arr)`** — разворот массива на месте
- **19. `concat(int[] arr1, int[] arr2)`** — объединение двух массивов
- **20. `deleteNegative(int[] arr)`** — новый массив без отрицательных элементов
